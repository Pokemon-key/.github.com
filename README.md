Pokémon (short for Pocket Monsters) is a global Japanese media franchise created by Satoshi Tajiri in 1996. It centers on a shared universe where humans—known as Trainers—catch, train, and battle fictional creatures called Pokémon. Wikipedia

## Key Elements of the Franchise

• Core Concept: Trainers capture species using spherical devices called Poké Balls, build teams, fill out their Pokédex (an electronic encyclopedia of all species), and battle other Trainers to win badges and titles.
• Video Games: Main-series role-playing games developed by Game Freak (starting with Red and Green on the Game Boy) alongside spin-offs like the mobile game Pokémon GO.
• Trading Card Game (TCG): A massive competitive and collectible card game played and collected worldwide.
• Anime & Films: Long-running animated television series and feature films following various heroes and their partner Pokémon across different regions.
• Management & Storage: Players can organize and transfer creatures across compatible platforms using Pokémon HOME.
